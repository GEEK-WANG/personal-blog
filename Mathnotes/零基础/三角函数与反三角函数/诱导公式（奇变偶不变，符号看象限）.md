设 $k \in \mathbb{Z}$，则：
##### 正弦与余弦的诱导公式

| 角度 $\theta$ 的通项形式 | $\sin\theta$ | 角度 $\varphi$ 的通项形式 | $\cos\varphi$ |
| :---: | :---: | :---: | :---: |
| $\alpha + 2k\pi$ | $\sin\alpha$ | $\alpha + 2k\pi$ | $\cos\alpha$ |
| $-\alpha + 2k\pi$ | $-\sin\alpha$ | $-\alpha + 2k\pi$ | $\cos\alpha$ |
| $\pi - \alpha + 2k\pi$ | $\sin\alpha$ | $\pi - \alpha + 2k\pi$ | $-\cos\alpha$ |
| $\pi + \alpha + 2k\pi$ | $-\sin\alpha$ | $\pi + \alpha + 2k\pi$ | $-\cos\alpha$ |
| $\frac{\pi}{2} - \alpha + 2k\pi$ | $\cos\alpha$ | $\frac{\pi}{2} - \alpha + 2k\pi$ | $\sin\alpha$ |
| $\frac{\pi}{2} + \alpha + 2k\pi$ | $\cos\alpha$ | $\frac{\pi}{2} + \alpha + 2k\pi$ | $-\sin\alpha$ |
| $\frac{3\pi}{2} - \alpha + 2k\pi$ | $-\cos\alpha$ | $\frac{3\pi}{2} - \alpha + 2k\pi$ | $-\sin\alpha$ |
| $\frac{3\pi}{2} + \alpha + 2k\pi$ | $-\cos\alpha$ | $\frac{3\pi}{2} + \alpha + 2k\pi$ | $\sin\alpha$ |

##### 正切与余切的诱导公式

| 角度 $\theta$ 的通项形式 | $\tan\theta$ | 角度 $\varphi$ 的通项形式 | $\cot\varphi$ |
| :---: | :---: | :---: | :---: |
| $\alpha + k\pi$ | $\tan\alpha$ | $\alpha + k\pi$ | $\cot\alpha$ |
| $-\alpha + k\pi$ | $-\tan\alpha$ | $-\alpha + k\pi$ | $-\cot\alpha$ |
| $\pi - \alpha + k\pi$ | $-\tan\alpha$ | $\pi - \alpha + k\pi$ | $-\cot\alpha$ |
| $\pi + \alpha + k\pi$ | $\tan\alpha$ | $\pi + \alpha + k\pi$ | $\cot\alpha$ |
| $\frac{\pi}{2} - \alpha + k\pi$ | $\cot\alpha$ | $\frac{\pi}{2} - \alpha + k\pi$ | $\tan\alpha$ |
| $\frac{\pi}{2} + \alpha + k\pi$ | $-\cot\alpha$ | $\frac{\pi}{2} + \alpha + k\pi$ | $-\tan\alpha$ |
| $\frac{3\pi}{2} - \alpha + k\pi$ | $\cot\alpha$ | $\frac{3\pi}{2} - \alpha + k\pi$ | $\tan\alpha$ |
| $\frac{3\pi}{2} + \alpha + k\pi$ | $-\cot\alpha$ | $\frac{3\pi}{2} + \alpha + k\pi$ | $-\tan\alpha$ |
