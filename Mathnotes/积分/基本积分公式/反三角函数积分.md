16. $$\int \frac{1}{\sqrt{1-x^2}} \, dx = \arcsin x + C$$
17. $$\int \frac{1}{\sqrt{1-x^2}} \, dx = -\arccos x + C$$
18. $$\int \frac{1}{1+x^2} \, dx = \arctan x + C$$
19. $$\int \frac{1}{ 1- x^2} \, dx = \frac{1}{2} \ln\left| \frac{x+1}{x-1} \right| + C$$
20. $$\int \frac{1}{|x|\sqrt{x^2-1}} \, dx = \operatorname{arcsec} |x| + C$$
21. $$\int \frac{1}{|x|\sqrt{x^2-1}} \, dx = -\operatorname{arccsc} |x| + C$$
