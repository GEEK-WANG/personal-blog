###  1.含有 $ax+b$ 的积分

30. $$\int (ax + b)^n \, dx = \frac{(ax+b)^{n+1}}{a(n+1)} + C \quad (n \neq -1)$$
31. $$\int \frac{1}{ax+b} \, dx = \frac{1}{a} \ln|ax+b| + C$$
32. $$\int \frac{x}{ax+b} \, dx = \frac{x}{a} - \frac{b}{a^2} \ln|ax+b| + C$$
33. $$\int \frac{x^2}{ax+b} \, dx = \frac{1}{a^3} \left[ \frac{(ax+b)^2}{2} - 2b(ax+b) + b^2 \ln|ax+b| \right] + C$$
34. $$\int \frac{1}{x(ax+b)} \, dx = \frac{1}{b} \ln\left| \frac{x}{ax+b} \right| + C$$
35. $$\int \frac{1}{x^2(ax+b)} \, dx = -\frac{1}{bx} + \frac{a}{b^2} \ln\left| \frac{ax+b}{x} \right| + C$$
### 2. 含有 $\sqrt{ax+b}$ 的积分

36. $$\int \sqrt{ax+b} \, dx = \frac{2}{3a} (ax+b)^{3/2} + C$$
37. $$\int x \sqrt{ax+b} \, dx = \frac{2}{15a^2} (3ax - 2b)(ax+b)^{3/2} + C$$
38. $$\int \frac{1}{\sqrt{ax+b}} \, dx = \frac{2}{a} \sqrt{ax+b} + C$$
39. $$\int \frac{x}{\sqrt{ax+b}} \, dx = \frac{2}{3a^2} (ax - 2b) \sqrt{ax+b} + C$$
40. $$\int \frac{1}{x\sqrt{ax+b}} \, dx = 
\begin{cases} 
\frac{1}{\sqrt{b}} \ln\left| \frac{\sqrt{ax+b}-\sqrt{b}}{\sqrt{ax+b}+\sqrt{b}} \right| + C & (b > 0) \\ 
\frac{2}{\sqrt{-b}} \arctan \sqrt{\frac{ax+b}{-b}} + C & (b < 0)
\end{cases}$$
