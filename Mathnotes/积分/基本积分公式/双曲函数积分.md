[[双曲函数]]
22. $$\int \sinh x \, dx = \cosh x + C$$
23. $$\int \cosh x \, dx = \sinh x + C$$
24. $$\int \tanh x \, dx = \ln(\cosh x) + C$$
25. $$\int \coth x \, dx = \ln|\sinh x| + C$$
26. $$\int \operatorname{sech}^2 x \, dx = \tanh x + C$$
27. $$\int \operatorname{csch}^2 x \, dx = -\coth x + C$$
28. $$\int \operatorname{sech} x \tanh x \, dx = -\operatorname{sech} x + C$$
29. $$\int \operatorname{csch} x \coth x \, dx = -\operatorname{csch} x + C$$
