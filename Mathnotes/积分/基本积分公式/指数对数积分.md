| 序号  | 积分公式                                                                                                      |
| :-: | :-------------------------------------------------------------------------------------------------------- |
| 66  | $$\int \ln x \, dx = x \ln x - x + C$$                                                                    |
| 67  | $$\int \log_a x \, dx = \frac{x}{\ln a} (\ln x - 1) + C$$                                                 |
| 68  | $$\int x^n \ln x \, dx = \frac{x^{n+1}}{n+1} \left( \ln x - \frac{1}{n+1} \right) + C \quad (n \neq -1)$$ |
| 69  | $$\int e^{ax} \, dx = \frac{e^{ax}}{a} + C$$                                                              |
| 70  | $$\int x e^{ax} \, dx = \frac{e^{ax}}{a^2} (ax - 1) + C$$                                                 |
| 71  | $$\int x^n e^{ax} \, dx = \frac{x^n e^{ax}}{a} - \frac{n}{a} \int x^{n-1} e^{ax} \, dx$$                  |
| 72  | $$\int e^{ax} \sin bx \, dx = \frac{e^{ax} (a \sin bx - b \cos bx)}{a^2 + b^2} + C$$                      |
| 73  | $$\int e^{ax} \cos bx \, dx = \frac{e^{ax} (a \cos bx + b \sin bx)}{a^2 + b^2} + C$$                      |
