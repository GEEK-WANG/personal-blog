| 积分公式                                                                                     |
| :--------------------------------------------------------------------------------------- |
| $$\int_0^{\frac{\pi}{2}} \sin x \, dx = \int_0^{\frac{\pi}{2}} \cos x \, dx = 1$$        |
| $$\int_0^\pi \sin x \, dx = 2$$                                                          |
| $$\int_0^\pi \cos x \, dx = 0$$                                                          |
| $$\int_0^{+\infty} e^{-ax} \, dx = \frac{1}{a} \quad (a > 0)$$                           |
| $$\int_0^{+\infty} x^n e^{-ax} \, dx = \frac{n!}{a^{n+1}} \quad (a > 0, n \text{为正整数})$$ |
| $$\int_0^{+\infty} e^{-x^2} \, dx = \frac{\sqrt{\pi}}{2}$$                               |
| $$\int_0^{+\infty} \frac{\sin x}{x} \, dx = \frac{\pi}{2}$$                              |
