HTML 基础语法

学习 Web 开发 / 核心学习模块 / 使用 HTML 构建 Web

什么是 HTML？

HTML（HyperText Markup Language，超文本标记语言）是一种标记语言，它告诉 Web 浏览器如何组织你访问的网页。HTML 由一系列的元素组成，你使用这些元素来包围、包装或标记内容的不同部分，使其以某种方式显示或运作。

剖析一个 HTML 元素

一个 HTML 元素通常由以下部分组成：

<p class="example">这是一个段落。</p>

开始标签：由元素名称和可选属性组成，用尖括号包裹。

内容：元素包含的文本或其他元素。

结束标签：与开始标签类似，但在元素名称前有一个斜杠。

属性

属性提供了关于元素的额外信息，不会出现在内容中。属性通常包含名称和值：

<img src="image.jpg" alt="描述文字" width="300">
